## 👨‍💻 Sobre mí

- 💻 **Desarrollador Full-Stack (Semi Senior)** radicado en Argentina, especializado en la convergencia de **backend sólido** con **frontend moderno y reactivo**.
- 🏗️ Especializado en diseñar y desplegar **sistemas de gestión, dashboards analíticos, APIs REST y plataformas productivas end-to-end** combinando la robustez de **Symfony (PHP)** con la agilidad de **React / Next.js / Astro**.
- 📐 Metodología centrada en **Clean Code, Arquitectura MVC, tipado estricto (TypeScript)**, alta accesibilidad (a11y), refactorización continua y optimización de consultas SQL en producción.
